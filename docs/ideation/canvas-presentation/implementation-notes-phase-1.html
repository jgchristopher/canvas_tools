Process — scout skipped

Context
execute-spec invokes the ideation:scout agent from the session working directory, which is the jcOS vault, not the repo worktree.
Decision
Explored inline. The codebase was already mapped while building PR #1, and every pattern file named in the spec was read directly.
Alternative
Run the scout with absolute paths, but its globbing and grep would have been rooted in the vault.

Viewport spike — animation not observed live

Context
The spec asked to confirm that writing tx/ty/tZoom animates the view. The Obsidian window was hidden (visibilityState hidden), so requestAnimationFrame never fired.
Decision
Confirmed the easing and clamping from the frame-loop source, and confirmed live that a viewport write causes 0 saves and no data or file change. The visual animation check moves to the Phase 2 manual tests.
Alternative
Ask John to bring Obsidian to the front mid-run.

viewport-fit — zero-size screen

Context
The spec said fitRect should return "the current viewport unchanged" for a 0×0 screen, but fitRect is pure and has no current viewport.
Decision
For a 0×0 screen, fitRect returns the rect center at zoom 0 (finite and harmless). Callers in Phase 3 skip setViewport when getScreenSize() is 0×0.
Alternative
Pass the current viewport into fitRect, which would couple the pure function to canvas state.

viewport-fit tests — round-trip zooms

Context
The spec listed round-trip zooms -2, 0, 1.5, and 3. The spike then found the canvas clamps zoom to [-4, 1].
Decision
Round-trip at -2, 0, 0.5, and 1, the valid range. Values above 1 are covered by the clamp test instead, since they can never be captured.
Alternative
Keep 1.5 and 3, which would fail the round trip by design.

canvas-data — result type name

Context
The spec named the generic helper result ReadResult<T>.
Decision
Named it KeyedRead<T>, because path-model already exports a non-generic ReadResult and two types with the same name would be confusing.
Alternative
Reuse the name ReadResult.

slide-model — addSlide trims

Decision

Alternative
Store the name exactly as given on add.
